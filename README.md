# Bubino 3DS
This is a 3DS homebrew game. Collect cakes by controlling a Bubino on the top/bottom screen. Score count included. Cakes spawn every 5 seconds randomly.

# How do i play????
Use the Circle Pad or the D-Pad to move a Bubino. 
Press A to switch between the Bubino on the Top/Bottom screen.
Go to a cake to eat it.
